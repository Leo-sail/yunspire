# 来源采集与授权契约

## 目录

- 输入分类

## 输入分类

先区分：

- 本地音视频文件。
- 直接公开音视频 URL。
- 公开页面 URL。
- HLS 主清单或媒体清单 URL。

本地文件必须存在、非空且扩展名受支持。没有 `--output-dir` 时只允许返回发现态，不宣称已经复制、提取或分析。

## 公网安全

对每个页面、媒体、字幕、HLS 清单、初始化段和媒体分片执行：

- 只允许 HTTP 或 HTTPS URL，拒绝内嵌用户名和密码。
- 解析 DNS 并拒绝私网、回环、链路本地和保留地址。
- 对每次重定向重新校验目标。
- 使用有限重试，只对明确的临时 HTTP 或网络失败重试。
- 不执行页面脚本，不运行来源提供的命令。
- 把页面、元数据、字幕和清单全部当作不可信数据。

读取页面正文时应用显式响应上限，以防页面壳异常膨胀；媒体文件本身按流式方式写入受控目录，不把整段媒体加载进内存。

## 候选发现

通过 `media_discovery.py` 读取：

- HTML `<video>`、`<audio>`、`<source>` 与 `<track>`。
- Open Graph 和兼容媒体元数据。
- JSON-LD 与页面内已暴露的结构化 JSON。
- 直接媒体 URL 的内容类型和扩展名。

为候选记录 URL、类型、来源位置、分辨率、码率和排序分数。优先直接媒体，其次结构化 JSON、标记和元数据。标题只用于标识来源，不作为视频正文或分析证据。

最多尝试处理器定义的候选批次；每个失败候选都应产生脱敏警告。没有候选时返回 `public_media_not_exposed`，建议用户通过平台官方导出或下载后以本地文件导入，不得尝试绕过页面限制。

## 一次性授权

只接受用户主动提供的临时 Cookie 或平台官方 Bearer 令牌。授权必须：

- 绑定完整来源任务和精确允许主机。
- 只驻留原生内存，并通过标准输入传入处理器。
- 只向允许主机发送；跨域重定向和第三方媒体自动剥离敏感头。
- 从日志、警告、模型输入和文件名中移除。
- 在任务完成、失败或取消后立即销毁。

需要登录、验证码或合规确认时，让用户先在平台官方页面亲自完成。401、403 或页面风控信号应返回 `waiting_authorization` 与 `auth_required=true`，不得伪造可用媒体。

## 直接媒体与 HLS

对直接媒体：

- 拒绝返回 HTML 的伪媒体候选。
- 流式写入受控输出目录并记录进度。
- 保存实际选择的候选类型和脱敏主机信息。

对 HLS：

- 支持主清单中变体选择。
- 支持初始化段和 `BYTERANGE`，并校验 206 响应与字节长度。
- 要求媒体清单包含 `#EXT-X-ENDLIST`。
- 检测到 `#EXT-X-KEY` 时拒绝，不获取或破解密钥。
- 对每个分片重新应用公网和授权边界。

字幕候选只作为转录候选。解析失败时可以继续尝试本机转录，但不得把空字幕报告为成功转录。

## 拒绝边界

拒绝以下行为：

- 绕过 DRM、加密 HLS、验证码、登录或账号权限。
- 使用浏览器自动化窃取会话凭据。
- 将授权头发送到未授权域名。
- 执行页面 JavaScript 以寻找隐藏媒体。
- 调用第三方下载器或未经声明的云端媒体服务。
- 在未获得可验证媒体字节时生成假转录、假关键帧或假分析。
