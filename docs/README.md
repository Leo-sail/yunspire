## 🚀 快速开始

### 开发新功能

1. **阅读主文档**: [架构重构路线图](./ARCHITECTURE_REFACTORING_ROADMAP.md)
2. **确认位置**: 功能应该在哪个插件中实现
3. **遵循规范**: 参考 AI 助手开发指引
4. **编写测试**: 单元测试覆盖率 > 80%
5. **提交审查**: Code Review 通过后合并

### 添加新插件

1. **设计插件**: 定义职责和边界
2. **实现接口**: 实现 `YunspirePlugin` trait
3. **编写迁移**: 提供数据库 schema
4. **注册插件**: 在 `PluginRegistry` 中注册
5. **文档完善**: 编写插件使用文档
